# 📚 Book Journal

A modern and intuitive **Book Journal** application for keeping track of your reading journey.

Users can organize their books, keep track of their reading progress, and maintain a personal collection in one place.

## ✨ Features

* 📖 Add and manage books
* 🔍 Search and find books easily
* 📝 Keep track of reading information
* ⭐ Rate and review books
* 📚 Organize your personal book collection
* 📊 Track your reading progress
* 💻 Responsive and user-friendly interface

## 🛠️ Tech Stack

* **React**
* **JavaScript**
* **Vite**
* **Tailwind CSS**
* **React Router**
